================================================================================
🐙 STAP 2: GITHUB ACCOUNT MAKEN EN JE CODE UPLOADEN
================================================================================

GitHub bewaart je broncode veilig online. Zodra GitHub gekoppeld is aan DigitalOcean,
wordt je website automatisch geüpdatet zodra je iets aanpast!

--------------------------------------------------------------------------------
1. GITHUB ACCOUNT MAKEN:
--------------------------------------------------------------------------------
1. Ga naar https://github.com en maak een gratis account aan (als je die nog niet hebt).

--------------------------------------------------------------------------------
2. NIEUWE REPOSITORY (PROJECT) AANMAKEN OP GITHUB:
--------------------------------------------------------------------------------
1. Klik rechtsboven op het plusje (+) -> "New repository".
2. Geef je project een naam (bijvoorbeeld: 'mijn-kleurplaten-website').
3. Zet de repository op "Private" (privé) of "Public" (openbaar).
4. Laat "Add a README file" en ".gitignore" UITGEVINKT (we hebben deze al!).
5. Klik op de groene knop "Create repository".

--------------------------------------------------------------------------------
3. JE CODE NAAR GITHUB UPLOADEN (VIA TERMINAL):
--------------------------------------------------------------------------------
Open je terminal in deze projectmap en voer de volgende regels één voor één uit:

git init
git add .
git commit -m "Eerste versie van mijn kleurplaten website"
git branch -M main
git remote add origin https://github.com/JOUW-GEBRUIKERSNAAM/JOUW-REPOSITORIE-NAAM.git
git push -u origin main

(Vervang de link hierboven met de exacte link die GitHub je laat zien).

--------------------------------------------------------------------------------
4. TOEKOMSTIGE AANPASSINGEN DOORVOEREN:
--------------------------------------------------------------------------------
Heb je nieuwe kleurplaten of teksten toegevoegd? Voer dan simpelweg dit uit:

git add .
git commit -m "Nieuwe kleurplaten toegevoegd"
git push

DigitalOcean herkent dit automatisch en zet binnen 2 minuten je nieuwe versie online!
