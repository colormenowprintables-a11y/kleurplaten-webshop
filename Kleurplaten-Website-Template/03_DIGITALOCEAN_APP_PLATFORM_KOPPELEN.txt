================================================================================
🌊 STAP 3: DIGITALOCEAN APP PLATFORM KOPPELEN & LIVE ZETTEN
================================================================================

DigitalOcean App Platform is dé perfecte host voor Next.js websites. Het is stabiel,
supersnel en vereist geen ingewikkeld serverbeheer.

--------------------------------------------------------------------------------
1. ACCOUNT AANMAKEN BIJ DIGITALOCEAN:
--------------------------------------------------------------------------------
1. Ga naar https://www.digitalocean.com en log in of maak een account.

--------------------------------------------------------------------------------
2. NIEUWE APP AANMAKEN:
--------------------------------------------------------------------------------
1. Klik in het DigitalOcean dashboard linksboven op de groene knop "Create" -> "Apps".
2. Kies bij de bron (Source) voor "GitHub".
3. Geef DigitalOcean toestemming om je GitHub repository te lezen.
4. Selecteer je repository (bijv. 'mijn-kleurplaten-website') en kies branch 'main'.
5. Vink "Autodeploy" AAN (zodat elke GitHub update automatisch live gaat).
6. Klik op "Next".

--------------------------------------------------------------------------------
3. INSTELLINGEN CONTROLEREN (BUILD & RUN COMMANDS):
--------------------------------------------------------------------------------
DigitalOcean herkent Next.js automatisch. Controleer of het volgende staat ingesteld:
- Type: Web Service
- Build Command: npm run build
- Run Command: npm start
- HTTP Port: 3000
- Plan / Grootte: Basic ($5/maand of $12/maand afhankelijk van je bezoekersaantal).

Klik op "Next" -> kies een datacenter regio (bijv. Frankfurt of Amsterdam) -> "Create App".

Binnen 3-4 minuten bouwt DigitalOcean je website en krijg je een live link
(bijvoorbeeld: https://mijn-kleurplaten-website-abc12.ondigitalocean.app).

--------------------------------------------------------------------------------
4. JE EIGEN DOMEINNAAM KOPPELEN (BIJV. WWW.MIJNKLEURPLATEN.NL):
--------------------------------------------------------------------------------
1. Ga in DigitalOcean naar je App -> tabblad "Settings" -> "Domains".
2. Klik op "Add Domain" en vul je domeinnaam in (bijv. mijnkleurplaten.nl en www.mijnkleurplaten.nl).
3. DigitalOcean geeft je de DNS-records (CNAME / A-record).
4. Log in bij je domeinprovider (waar je je domeinnaam hebt gekocht, bijv. TransIP, MijnHost, Hostnet).
5. Voeg de CNAME of A-records toe in je DNS-instellingen.
6. DigitalOcean regelt automatisch een gratis beveiligd SSL-certificaat (het groene slotje / HTTPS).
