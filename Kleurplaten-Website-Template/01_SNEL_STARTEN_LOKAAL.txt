================================================================================
🚀 STAP 1: WEBSITE LOKAAL OPSTARTEN & TESTEN
================================================================================

Welkom bij je nieuwe moderne Kleurplaten Website! Deze website is gebouwd met 
Next.js (React & TypeScript). Hij is razendsnel, mobielvriendelijk en geoptimaliseerd
voor Google SEO en Pinterest.

--------------------------------------------------------------------------------
1. BENODIGDHEDEN OP JE COMPUTER:
--------------------------------------------------------------------------------
- Node.js (versie 20 of hoger): Download gratis van https://nodejs.org (kies LTS)
- Code editor: Visual Studio Code of de Antigravity AI editor.

--------------------------------------------------------------------------------
2. WEBSITE DE EERSTE KEER INSTALLEREN:
--------------------------------------------------------------------------------
1. Open PowerShell of Terminal in deze projectmap.
2. Typ het volgende commando en druk op Enter:

   npm install

   (Dit downloadt automatisch alle benodigde pakketten in een mapje genaamd 'node_modules')

--------------------------------------------------------------------------------
3. DE WEBSITE STARTEN OM TE BEKIJKEN:
--------------------------------------------------------------------------------
1. Typ in de terminal:

   npm run dev

2. Open je internetbrowser (Chrome, Edge, Safari) en ga naar:

   http://localhost:3000

🎉 Je ziet nu direct je werkende website live op je eigen computer!

--------------------------------------------------------------------------------
4. STOPPEN:
--------------------------------------------------------------------------------
Wil je de lokale testserver stoppen? Druk in je terminal op:
Ctrl + C (en typ 'y' als erom gevraagd wordt).
