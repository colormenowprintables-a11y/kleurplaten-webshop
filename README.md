# 🎨 Kleurplaten Website Template (Next.js & TypeScript)

Een complete, moderne, razendsnelle website voor het publiceren en printen van kleurplaten en knutselwerkbladen.

## 📁 Handleidingen & Documentatie
Lees de genummerde `.txt` bestanden in deze map voor eenvoudige stap-voor-stap uitleg:
- `01_SNEL_STARTEN_LOKAAL.txt` - Hoe je de site installeert en op je eigen computer bekijkt.
- `02_GITHUB_REPOSITORIE_MAKEN_EN_UPLOADEN.txt` - Hoe je je code op GitHub zet.
- `03_DIGITALOCEAN_APP_PLATFORM_KOPPELEN.txt` - Hoe je de website live zet op DigitalOcean met je eigen domein.
- `04_EIGEN_KLEURPLATEN_EN_FOTOS_TOEVOEGEN.txt` - Hoe je nieuwe categorieën en kleurplaten toevoegt.
- `05_BRANDING_EN_NAAM_AANPASSEN.txt` - Hoe je het logo, de naam en kleuren aanpast.
- `AGENTS.md` - Instructies voor AI programmeer-assistenten (Antigravity).

## 🚀 Snelle Start
```bash
# 1. Installeer dependencies
npm install

# 2. Genereer de zoekindex
npm run generate:search

# 3. Start de lokale ontwikkelserver
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in je browser.
